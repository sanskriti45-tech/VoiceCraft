# Day 2 voice prompts

Speak these to your coding tool with Wispr Flow while screen-recording. Say them in your own words.

## Voice Remix
1. "Add Voice Remix to the case study screen. The user taps a section to select it, taps a microphone button, and speaks an edit instruction like make it shorter or make it more professional."
2. "Add an API endpoint that takes the section text and the spoken instruction and uses OpenAI to rewrite only that section. Never invent facts. Return JSON."
3. "When the section updates, animate the new text in. Add an undo button and let the user say undo."
4. "Let the user say the section name, like make the problem section shorter, and apply the edit to that section."
5. "Add quick buttons for the most common edits: shorter, more professional, more technical, for recruiters."

## Upload + Portfolio Reader
6. "Add an upload flow for a resume. Accept PDF, DOCX and text files up to five megabytes with drag and drop."
7. "Extract the text on the backend and use OpenAI to structure it into experience, projects, skills and education, plus a spoken first person narration for each section."
8. "Create a portfolio reader screen that reads the narration aloud with the browser speech synthesis. Add play, pause, next, previous, a speed control and a voice picker."
9. "Highlight the section being read and the current sentence, and show a progress bar."

## Iteration prompts (these make the video credible)
- "Long sections are getting cut off when read aloud. Split the text into shorter sentences."
- "When I leave the reader screen, make sure the audio stops."
- "The open last portfolio button should appear right after I upload one."
