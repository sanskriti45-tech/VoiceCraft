# Demo video plan

The task needs a video that **shows you using Wispr Flow and your voice to build the project**, not just the final result. Record continuously and keep Wispr Flow visibly active.

## Structure (aim for 5 to 8 minutes)

1. **Opening (15 to 20s)** Face or voice-over: "Most portfolios are static. VoiceCraft makes your portfolio something you speak, present, and practice, and I built the whole thing with my voice using Wispr Flow."
2. **The voice-driven build (majority of the video)** Screen-record your editor and your coding tool. Dictate each feature as a prompt (see `DAY1/2/3_VOICE_PROMPTS.md`), show the result, then dictate a fix or improvement. Real iteration is what shows the voice workflow works.
3. **Product walkthrough (2 to 3 min)**
   - Speak a project → case study appears → Present it
   - Voice Remix: "make the problem section shorter", then "undo"
   - Upload resume → Portfolio Reader plays with highlighting
   - Interview Mode: answer 2 to 3 questions by voice → summary screen
4. **Closing (10s)** "From building the product to using it, voice drives the entire experience."

## Before you record
- [ ] Wispr Flow account created through `https://ref.wisprflow.ai/hhg`
- [ ] Chrome or Edge, mic permission allowed, headphones on (so Interview Mode doesn't hear the questions)
- [ ] `.env` has a working `OPENAI_API_KEY`; run through every feature once
- [ ] A realistic resume ready to upload
- [ ] Screen recorder set to capture the editor, the browser, and system audio if possible
