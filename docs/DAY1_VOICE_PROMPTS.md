# Day 1 voice prompts

Speak these to your coding tool with Wispr Flow while screen-recording, one at a time.
Say them in your own words; these are a guide, not a script.

1. "Create a FastAPI project called VoiceCraft with an app folder and a static folder. Serve a single page app from the static folder and add a health check endpoint."
2. "Create a premium dark landing page for VoiceCraft with a strong editorial portfolio aesthetic. Large serif headline that says Speak an idea, build the story, one orange accent color, and a Create from Voice button."
3. "Add a voice input screen where the user can describe their project. Use the browser speech recognition API, show the transcript live as I speak, and keep listening until I press stop."
4. "Add an animated waveform under the microphone button that reacts to my real microphone level."
5. "Add an API endpoint that takes the transcript and uses OpenAI to turn it into a case study with sections for problem, idea, approach, technology, result and lessons learned. Return strict JSON."
6. "Show the generated case study as a clean editorial page with numbered sections."
7. "Create a presentation mode that turns those sections into a cinematic case study. One section per slide, huge typography, smooth fade transitions, arrow key navigation, a progress bar, and a fullscreen button."

## Iteration prompts (these make the video credible)

- "The transcript is cutting off when I pause. Make the microphone keep listening until I press stop."
- "The presentation transitions feel abrupt. Make them smoother."
- "Save the last case study so it is still there if I refresh the page."
