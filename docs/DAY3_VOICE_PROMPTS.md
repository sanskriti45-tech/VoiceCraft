# Day 3 voice prompts

Speak these to your coding tool with Wispr Flow while screen-recording. Say them in your own words.

## Interview Mode
1. "Add an Interview Mode button to the portfolio reader. It starts a mock interview of five questions based on the uploaded portfolio."
2. "Add an API endpoint that takes the portfolio and the questions and answers so far and returns the next interview question. Ground every question in the real projects and roles. If an answer was vague, ask a follow-up. Make the last question forward looking."
3. "Speak each question out loud using speech synthesis. Let me answer with the microphone, show my words live, and let me edit or type the answer if I prefer."
4. "Add a replay question button, a skip button, and progress dots for the five questions."
5. "Make sure the microphone stops listening while the question is being read, so it doesn't hear itself."

## Summary screen
6. "Add an API endpoint that scores the whole interview on clarity, depth, specificity and structure, gives an overall score out of ten, lists strengths and improvements, feedback for each question, and what to rehearse next. Be honest and don't inflate scores for short or skipped answers."
7. "Build a summary screen with a score ring, animated score bars, strengths, areas to work on, expandable question by question feedback, and a rehearse next list."
8. "Add a hear summary button that reads the feedback aloud, and a practice again button."

## Polish and iteration prompts (these make the video credible)
- "If the AI request fails, show a clear error with a retry button instead of getting stuck."
- "The submit button is off screen on my laptop. Tighten the layout so it always fits."
- "When I skip a question, make the feedback say it was skipped instead of scoring it."
- "Add automated tests for the API endpoints."
